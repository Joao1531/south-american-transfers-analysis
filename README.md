# South American Transfers Analysis

A market-intelligence project on South American top-flight transfer markets (2020–2026). It started as a Chilean Primera División project built around **Audax Italiano**, and now also covers Uruguay, Paraguay, and Peru. It scrapes Transfermarkt, consolidates every transfer touching each league's club universe into a canonical dataset per league, and renders a self-contained HTML dashboard per league. Chile additionally gets a club-focused intelligence report for Audax Italiano.

## What's inside

| Path | Description |
|---|---|
| `scripts/` | Numbered Python scripts forming the full pipeline (run in order), driven by `scripts/league_config.py` |
| `data/processed/` (Chile) and `data/processed/{uruguay,paraguay,peru}/` | Clean outputs per league: canonical transfers, flat CSV, player histories |
| `data/raw/` | Small cached source assets kept in-repo: club lists per league, CMF/SADP registry (Chile only), club crests (shared across leagues) |
| `dashboard/index.html` | "South American Transfer Market 2020–2026" — one interactive dashboard with all four leagues and a League filter (self-contained, crests embedded as base64). A transfer between two tracked leagues is kept once |
| `dashboard/{chile,uruguay,paraguay,peru}/index.html` | Optional single-league builds of the same dashboard (`05_build_dashboard.py --league X`) |
| `dashboard/index_es.html`, `dashboard/{league}/index_es.html` | Spanish versions of the same dashboards (`05_build_dashboard.py --lang es`; translations live in `scripts/i18n_es.py`) |
| `report/index.html` | "Audax Transfer Intelligence" — market report for Audax Italiano with narrative sections (Chile only) |
| `combined/index.html` | Tabbed artifact: Audax report + one transfer dashboard per country (Chile, Uruguay, Paraguay, Peru), iframe `srcdoc` isolation |
| `combined/index_es.html` | Same artifact fully in Spanish (report + four dashboards). Build with `07_build_report.py --lang es`, `05_build_dashboard.py --league X --lang es` for each country, then `09_build_combined.py --lang es`; translations in `scripts/i18n_es.py`, `scripts/i18n_report_es.py` and `report/agent_sections_es/` |

## Pipeline

Every scraping/build script accepts `--league {chile,uruguay,paraguay,peru}` (default `chile`), resolving all paths and per-league copy from `scripts/league_config.py`. Passing no flag reproduces Chile's original behavior exactly.

0. **`00_fetch_league_clubs.py --league X`** — Uruguay/Paraguay/Peru only. Auto-discovers each season's participating clubs from Transfermarkt's competition page (the Apertura tournament of each `saison_id` is used as a proxy for that season's club universe) → `data/raw/clubs_{league}.json`. Chile's equivalent file (`clubs_2020_2025.json`) was curated by hand and isn't regenerated by this script.
1. **`01_scrape_club_transfers.py`** — Scrapes arrivals/departures for every club that played in the league 2020–2025 → `transfers_raw.json`
2. **`02_scrape_transfer_details.py`** — Enriches each transfer from its detail page: market value at transfer, precise age, remaining contract, coaches involved → `transfer_details.json`
3. **`03_scrape_player_transfer_history.py`** — Fetches each player's full career history via Transfermarkt's internal JSON endpoint (`/ceapi/transferHistory/list`) to detect subsequent moves → `player_transfer_history.json`
4. **`04_consolidate.py`** — Deduplicates by `transfer_id` (a real transfer appears on both the selling and buying club pages), normalizes club names, classifies fees, detects sell-on/buy-back clauses (Chile only) → `canonical_transfers.json`. Run twice: once before step 8 (so it has player URLs to scrape), once after (to fold the bio enrichment in).
5. **`05_build_dashboard.py`** — Builds the dashboard with embedded crests. No flag: all four leagues merged → `dashboard/index.html`; `--league X`: a single league → `dashboard/X/index.html`
6. **`06_fetch_all_crests.py`** — Fetches 30×30 crest PNGs for every club appearing anywhere in the league's data (opponents included), shared across all leagues since IDs are global → `data/raw/crests_sq/`
7. **`07_build_report.py`** — Chile only. Builds the Audax report, combining local analytics (Big-3 profiles, sell-on tracker, loan stats) with narrative agent sections (`report/agent_sections/`) → `report/index.html`
8. **`08_scrape_player_profiles.py`** — Scrapes bio fields not on club pages: height, preferred foot, DOB, player agent, dual citizenship → `player_profiles.json`
9. **`09_build_combined.py`** — Merges the Audax report and the four per-country dashboards (`05_build_dashboard.py --league X`) into `combined/index.html`
10. **`10_export_flat_csv.py`** — Exports an analysis-ready flat CSV and the per-transfer subsequent-moves chain → `transfers_flat.csv`, `transfer_history.json`

### Differences for Uruguay/Paraguay/Peru vs. Chile

- No club-focused report; each has a country tab in the combined artifact and appears as a league in `dashboard/index.html`.
- No CMF/SADP regulatory cross-reference (`cmf_club_mapping.json`) — that's a Chile-specific corporate registry with no equivalent elsewhere.
- No sell-on/buy-back clause research (`sellon_research_merged.json`) — that was manual press research done only for Chile's paid transfers; the dashboard's "Clauses" filter and KPI are hidden when this data isn't present.
- Output field names differ slightly: Chile keeps its original `season_chile`/`from_is_chile_pd_scope`/`to_is_chile_pd_scope`/`both_sides_in_chile_pd_scope`; the other leagues use generic `season_league`/`from_is_league_scope`/`to_is_league_scope`/`both_sides_in_league_scope`.

## Dataset stats (Chile)

- **3,145 canonical transfers** across seasons **2020–2026**
- **1,298 unique players**; **81 Chilean clubs** appear in the network (25 in-scope league clubs)
- **252** transfers carry a market value at the time (2,525 records valued); **120 paid transfer fees** totalling **€119.4M** (max €5.2M)
- Fee breakdown: 1,190 free transfers · 764 end-of-loan returns · 669 free loans · 28 paid loans · 194 undisclosed
- Bio enrichment: 2,158 transfers with agent info · 579 dual-nationality players
- **CMF/SADP mapping**: each league club mapped to its regulatory entity (e.g. Colo-Colo → Blanco y Negro S.A., a bolsa-listed issuer rather than a SADP)

## Key features of the data model

- **Fee classification** into 9 types (`transfer_fee`, `loan_fee`, `loan_free`, `end_of_loan`, `free_transfer`, `undisclosed`, …) with EUR values where available
- **Club-perspective dedup**: arrivals/departures from both sides collapse into one record with clean `from_club`/`to_club`
- **Subsequent-transfers chain** per transfer — resale tracking used for sell-on clause research
- **Foreign-player quota support** via dual-nationality flags and citizenships

## Running it

```bash
pip install requests beautifulsoup4

# Chile (original pipeline, unchanged)
python scripts/01_scrape_club_transfers.py   # then 02..10 in order, no --league flag needed

# A new league
python scripts/00_fetch_league_clubs.py --league uruguay
python scripts/01_scrape_club_transfers.py --league uruguay   # then 02, 03, 04, 08, 04 (again), 06, 05, 10
```

Scripts are polite by design: single-threaded, disk-cached per page, ~1.1–1.3s delay between live requests, identifiable User-Agent. Re-runs are cheap — cached pages are never re-fetched. Run one league fully before starting the next, to keep request volume against Transfermarkt to a single stream at a time.

> Note: the full raw scrape cache (~514MB of HTML/JSON under `data/raw/{club_transfers,transfer_details,player_history,player_profiles,sellon_research}`) is intentionally not committed. Delete the cache folders to re-scrape from scratch, or keep them locally as the cache. This cache is shared across leagues (club/transfer/player IDs are global on Transfermarkt), so scraping a second league reuses anything already fetched for the first.

## Deliverables

Open `combined/index.html` in a browser — one tab per country plus the Audax report. Fonts load from Google Fonts; everything else (data, crests, styling) is embedded in the file. `dashboard/index.html` is the standalone version with all four leagues merged behind a League filter.
